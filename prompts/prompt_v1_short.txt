Your task is to find and extract all FINANCIAL COVENANTS from the provided text snippet.

The snippet is taken from a corporate debt / credit agreement. It may include tables (possibly in HTML-like text form).

What counts as a financial covenant
-----------------------------------
A financial covenant is a quantitative requirement or test, for example:
- interest coverage ratio, fixed charge coverage ratio
- leverage ratio / debt to EBITDA ratio / total debt to total capital
- minimum net worth / tangible net worth
- maximum capital expenditures
- minimum liquidity / minimum cash

Do NOT extract general negative covenants
----------------------------------------
Do NOT include operational / negative covenants that are not "financial tests", even if they appear near financial covenants.
Examples to EXCLUDE:
- limitations on Investments, Acquisitions, Indebtedness, Liens, Distributions, affiliate transactions, etc.
- “Borrower shall not make any Acquisition except …” (not a financial covenant)
- “Permit any Subsidiary to incur any Indebtedness except …” (not a financial covenant)
Even if these provisions contain numbers (e.g., dollar caps, percentages), EXCLUDE them when they are framed as restrictions on actions.
Only include covenants that test the borrower's financial condition/performance (e.g., a ratio, a minimum net worth, a maximum capex, a minimum liquidity).

Hard exclusion guardrails (common false positives)
-------------------------------------------------
If the snippet language is primarily about PERMITTED actions/baskets (not a financial test), EXCLUDE it.
In particular, EXCLUDE anything under headings or lead-ins like:
- "Limitation on Indebtedness"
- "Limitation on Liens"
- "Restricted Payments" / "Restricted Payment"
- "Limitation on Investments"
- "Limitation on Asset Sales" / "Disposition"
- "Negative Covenants"
Those are not financial covenants for this task, even if they use % of assets, % of EBITDA, or dollar caps.

Do NOT extract defined terms / definitions
-----------------------------------------
Do NOT output defined-term definitions as covenants.
Examples to EXCLUDE:
- "\"Consolidated Tangible Net Worth\" shall mean ..."
- "\"EBITDA\" means ..."
Definitions can contain formulas and numbers, but they are NOT covenant requirements.
Only output a covenant when the text states a REQUIREMENT/TEST such as:
- "shall maintain ... at least ..."
- "shall not permit ... to be less than ..."
- "shall not permit ... to exceed ..."

Do NOT extract performance pricing rules
--------------------------------------
Performance pricing rules state that the interest rate, margin, spread, fees, lease, or pricing on a loan can vary with the firm's financial ratios.
Those are NOT financial covenants for this task. Do NOT include them.

Important: use ONLY the snippet text
-----------------------------------
You may NOT assume you have the full agreement. Use ONLY what is explicitly present in the snippet.
If a covenant is mentioned but its numeric threshold is not stated in the snippet, do NOT guess.

Input format
------------
The input snippet will appear after the line:
=== INPUT ===

The snippet may include wrapper lines like:
  [[A0001]]
  label: financial_covenant
If you see anchor headers like [[A0001]], treat them as provenance markers.
Do NOT invent anchor IDs; only cite anchors that actually appear in the snippet.

Output format (STRICT)
----------------------
Return VALID JSON ONLY (no commentary, no markdown, no code fences).
The output MUST be a JSON LIST.
Each element MUST be a JSON object that includes at least these keys:

1. "name" (string): the financial statistic or ratio that is being limited (e.g., "interest coverage ratio").
2. "limit" (number or null): the numeric threshold value the statistic is not allowed to cross, as a SINGLE number.
   - If the covenant provides multiple thresholds (e.g., a schedule over time), output one object per threshold.
   - Convert percentage points to decimals (examples: 350% -> 3.5 ; 1.00% -> 0.01).
   - For ratio text like "2.25 to 1.00" or "2.25:1.00", use 2.25 as the number.
   - For money like "$21,000,000", output 21000000 (no commas, no currency symbols).
   - If the covenant threshold is NOT a single number (e.g., a formula like "the sum of $26,500,000 plus 90% of Net Income",
     or qualitative language like "a positive amount"), set "limit" to null and include an optional "limit_text" field (see below).
3. "start date" (string): the date the covenant begins to apply at this limit in "MM/DD/YYYY" format if explicitly stated, otherwise "NA".
4. "end date" (string): the date the covenant stops applying at this limit in "MM/DD/YYYY" format if explicitly stated, otherwise "NA".

Optional provenance (recommended when anchors are present)
---------------------------------------------------------
If anchor headers like [[A0001]] are present in the snippet, each covenant object MUST also include:
5. "source_refs" (array of strings): list of anchor IDs (e.g., ["A0127","A0128"]) that contain the numeric threshold and name.
6. "limit_text" (string): ONLY when "limit" is null. A short verbatim excerpt of the covenant threshold language from the snippet.

If anchor headers are present and you cannot cite at least one real anchor ID for an extracted covenant, do NOT output that covenant.

If no anchor headers are present, omit "source_refs" entirely (do not output fake anchor IDs).

If the snippet does not include any financial covenants, return an empty list:
[]
