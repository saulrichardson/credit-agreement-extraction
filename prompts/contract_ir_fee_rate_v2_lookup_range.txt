Semantic role (derived functions)

---------------------
AST grammar (ONLY these 3 node types)
---------------------
1) Literal node:
   {"lit": {"type": "...", "value": ...}}

2) Variable node:
   {"var": "name"}

3) Operator node:
   {"op": "op_name", "args": [<node>, ...]}

Literal types (v0.2):
- "rate" | "bps" | "decimal" | "money" | "integer" | "string" | "bool" | "date"

NUMERIC LITERALS MUST BE STRINGS.
- Do NOT include "%" signs (or "$", commas) inside numeric literal strings.
  - Example: 0.0700% MUST be encoded as {"lit":{"type":"rate","value":"0.0007"}} (not "0.0700%").
- Do NOT invent other AST shapes like {"if": ...} or {"op":"case", ...}. Use ONLY {"op":"if","args":[cond,then,else]}.

---------------------
Operator allowlist (v0.2)
---------------------
Conversions:
- bps_to_rate(bps)

Tables:
- lookup_range(table_id, key_value, lower_bound_col, lower_cmp_col, upper_bound_col, upper_cmp_col, value_col)
  - Matches EXACTLY ONE row where:
    - if lower bound is present: key_value > lower_bound (gt) or >= (gte)
    - if upper bound is present: key_value < upper_bound (lt) or <= (lte)
  - lower_cmp must be "gt" or "gte"
  - upper_cmp must be "lt" or "lte"
  - table_id and column name args MUST be AST string literal nodes:
    - {"lit":{"type":"string","value":"..."}}

=====================
RANGE TABLE ENCODING RULES
=====================
- Use a table to represent the schedule. Each row represents ONE bucket/tier.
- Each row MUST include:
  - bucket_label (string): exact bucket label text from the excerpt (e.g., ">= 4.75:1.0")
  - lower_bound (decimal or money): numeric lower bound (omit the cell if unbounded)
  - lower_cmp (string): "gt" or "gte" (omit the cell if lower_bound is omitted)
  - upper_bound (decimal or money): numeric upper bound (omit the cell if unbounded)
  - upper_cmp (string): "lt" or "lte" (omit the cell if upper_bound is omitted)
  - fee_bps (bps): fee percentage converted into bps

=====================
MISSING / AMBIGUOUS DATA POLICY
=====================
- If a bucket boundary is ambiguous in the excerpt, do NOT guess:
  - Emit a blocking open_item describing the ambiguity.
  - Return tables=[] and derived=[].
