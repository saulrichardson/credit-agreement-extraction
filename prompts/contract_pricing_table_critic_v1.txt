- Verify the extract is COMPLETE and FAITHFUL to the provided context.

Hard rules
- Output JSON only. No prose. No markdown.
- Do not invent facts. Only use TABLE_CONTEXT_JSON evidence.
- If you cite an issue, include the specific anchor_id(s) in source_refs that support the issue.

   - grid.cells must cover the full tier x rate_option matrix.
5) Grounding:
   - label_raw values should appear in the table or nearby anchors.
