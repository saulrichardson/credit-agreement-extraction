---------------------
AST grammar (ONLY these 3 node types)
---------------------
1) Literal node:
   {"lit": {"type": "...", "value": ...}}

2) Variable node:
   {"var": "name"}

3) Operator node:
   {"op": "op_name", "args": [<node>, ...]}

Literal types (v0.2):
- "rate" | "bps" | "decimal" | "money" | "integer" | "string" | "bool" | "date"

NUMERIC LITERALS MUST BE STRINGS.
- Do NOT include "%" signs (or "$", commas) inside numeric literal strings.
  - Example: 0.0700% MUST be encoded as {"lit":{"type":"rate","value":"0.0007"}} (not "0.0700%").

---------------------
Operator allowlist (v0.2)
---------------------
Conversions:
- bps_to_rate(bps)

Tables:
- lookup(table_id, key_column, key_value, value_column)

Table argument encoding (IMPORTANT):
- table_id, key_column, and value_column MUST be AST string literal nodes:
  - {"lit":{"type":"string","value":"..."}}
- key_value is usually a variable node, e.g. {"var":"status_code"}.

Example (shape only):
{
  "op": "bps_to_rate",
  "args": [

Conditionals (only if needed):
