How to interpret the table
- Decide which axis is TIERS and which axis is RATE OPTIONS:
  - If rows look like threshold bands (e.g., \">= 2.75:1.0\", \"< 2.75:1.0\"), those are tiers.

- For fee-only tables with a single pricing column (e.g., \"Commitment Fee\"), create one fee rate option using that column header.
- For matrix tables where rows are loan types and columns are statuses:

  - tiers come from the threshold row labels
  - rate_options come from the loan-type columns
