**You are extracting the pricing engine of a corporate credit agreement (EDGAR exhibits).**
Return **JSON only** that validates against the schema.

### 1) Object-level citation requirement (hard rule)

For **every object you output** that represents a pricing element (benchmark, fallback step, pricing grid, tier, facility, rate option, fee, schedule, rule, adjustment, condition clause, party/role), you MUST include:

```json
"source_refs": { "anchors": ["A0123"] }
```

* `anchors` must be a **non-empty** list of the exact `A####` IDs that support that object.
* If a field is `null` because the snippet is incomplete, cite the anchor where the missing detail is referenced (e.g., “as defined in Section …”) and explain briefly in `notes`.

### 2) Code + label rule (hard rule)

Whenever the schema provides `*_code` and `*_label`:

* `*_label` MUST capture the agreement’s exact term (e.g., “Alternate Base Rate”, “Adjusted Term SOFR”, “Commitment Fee”).
* `*_code` MUST be the closest matching normalized enum value; if you cannot confidently normalize, set `*_code` to `CUSTOM` or `OTHER` (as available) and rely on `*_label` + `*_text`.

### 3) No guessing

* Do not invent numbers, tier boundaries, formulas, payment dates, or benchmark sources.
* Use `null` for unknown values and describe what’s missing in `notes`.

### 4) Performance pricing grids

* Encode each table once as a `pricing_grid`.
* Use `columns[]` to represent each priced output (SOFR margin, ABR margin, commitment fee, LC fee, etc.).
* Use `tiers[]` to represent tier conditions and values.
* If “pricing level changes upon delivery of financials” / “missing financials => highest tier” exists, encode it in `pricing_grid.update_timing`.

### 5) Normalize units

* Use **bps** for spreads/margins and fee rates when they’re expressed as “x.xx%” margins/fees.
* Use **percent** for benchmark floors/caps or index-like floors unless it is clearly a spread.

### 6) Minimal but sufficient notes

* Put complex operative language into `*_text` fields and keep `notes` brief.
* Don’t paste long excerpts.
