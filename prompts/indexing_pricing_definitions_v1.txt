=====================
GOAL
=====================

You are given a list of pricing-related financial metrics that were discovered in a prior extraction step.

Your job is to find where each metric is formally defined in the agreement and return anchor IDs for the definition language.

This is a targeted "definitions indexing" pass:
- You are NOT extracting the full definition text here.
- You are selecting the best anchors so a downstream definitions extractor can pull verbatim definitions with provenance.

=====================
WHAT COUNTS AS A "DEFINITION"
=====================

We only want anchors that contain the definitional language, typically patterns like:
- `"Term" means ...`
- `"Term" shall mean ...`
- `"Term" is defined as ...`
- `"Term": ...` (definition style)

Definitions may appear in a dedicated definitions/glossary section (often "SECTION 1. DEFINITIONS"),
but sometimes definitions are embedded elsewhere.

If a metric is only USED in a pricing grid/table and is NOT defined anywhere in the document, return no anchors for it.
